## 如何使用本手册

1. **快速查找**：在总览表中定位需要的技能分类，点击跳转对应详细文档
2. **新手入门**：建议按顺序阅读 C++ 基础 → 蓝图系统 → 游戏框架 → 动画/场景
3. **按需查阅**：每个技能卡片包含适用场景、核心功能和知识概要

## 技能卡片格式说明

每个技能卡片包含以下信息：

- **技能名称**：唯一标识符，AI 助手通过此名称激活技能
- **适用场景**：何时应该使用该技能
- **核心内容**：技能覆盖的知识领域
- **引擎版本**：UE 5.7

> **提示**：这些技能是 AI 编程助手的领域知识扩展包。在与 AI 对话时，AI 会自动根据你的问题匹配并激活相关技能，你无需手动指定。
