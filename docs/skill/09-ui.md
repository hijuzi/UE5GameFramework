# 用户界面技能

UMG 控件蓝图和 Slate 底层界面系统。

---

## umg-and-slate

**适用于**：构建游戏 UI —— UMG（UUserWidget 控件蓝图）；C++ 控件生命周期（NativeConstruct/NativeTick/NativeDestruct）；Slate（低层 C++ 界面框架，SCompoundWidget/SListView/STreeView）；数据绑定（Property Binding / ViewModel）。

**核心内容**：UUserWidget（CreateWidget / AddToViewport / RemoveFromParent）；控件类型（TextBlock/Image/Button/ProgressBar/VerticalBox/CanvasPanel/ScrollBox）；Widget 蓝图生命周期（PreConstruct → Construct → NativeConstruct → NativeDestruct）；Slate 框架（SWidget / SCompoundWidget / SListView / STreeView / SOverlay）；Property Binding（属性绑定在蓝图中的实现）；Common UI Plugin（跨平台输入适配）；MVVM ViewModel 数据绑定模式。
